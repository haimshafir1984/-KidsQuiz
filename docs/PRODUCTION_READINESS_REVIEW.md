## עדכון 25.11.2026: בדיקות קבלה ותיקונים
- **שדה איפוס הסיסמה:** שורש התקלה ב-`useDialogA11y`: הפונקציה `onClose` נוצרה מחדש בכל רינדור, ולכן כל הקלדה הפעילה מחדש את האפקט והחזירה את המיקוד לכפתור "סגירה" (אפשר היה להקליד תו אחד בלבד). תוקן ב-ref. אומת בדפדפן מול שרת מקומי: 13 תווים נקלטו, האיפוס הצליח, הסיסמה הישנה נדחתה והחדשה התקבלה. התיקון חל גם על שאר המודאלים (עורך השאלות, אישור מחיקה).
- **חשבון חסום:** הודעה "חשבונך חסום. יש לפנות למנהל המערכת" (403) רק אחרי סיסמה נכונה. סיסמה שגויה מחזירה את ההודעה הרגילה ונספרת לנעילה.
- **ייצוא Excel:** `.xlsx` מהשרת, ארבעה גיליונות בעברית מימין לשמאל (פרטים אישיים, מנוי וחשבון, התקדמות, תוצאות), כותרות מעוצבות, רוחב עמודות, שם קובץ `שם_תאריך.xlsx`. בלי סיסמאות, hash, אסימונים או מזהים. נשאר למנהלים בלבד, והייצוא העצמי של תלמיד (`/auth/me/export`) נשאר JSON.
- **בדיקות:** 51 בדיקות שרת (10 חדשות): חשבון חסום, תוכן ה-Excel והרשאות, בידוד בין תלמידים, Turnstile מול Cloudflare (כולל אסימון חד-פעמי), עוגיות, יציאה, איפוס סיסמה מקצה לקצה וביטול סשנים.
- `exceljs` מוסיף התראה בינונית ב-`uuid` פנימי (v3/v5/v6 עם `buf` מפורש). הקוד שלנו לא קורא לשימוש הזה, ולכן אינה ניתנת לניצול.

## מה נבדק ונמצא תקין
| תחום | ממצא |
|---|---|
| Turnstile בשרת | האימות נעשה בשרת מול Cloudflare, לפני כל בדיקה אחרת בהרשמה. בלי Token או עם Token לא תקין ההרשמה נדחית (400). כשל בשירות האימות חוסם (fail-closed). מדלגים עליו רק כש-`TURNSTILE_SECRET` ריק. |
| SQL Injection | כל השאילתות עם פרמטרים. הרכבת `UPDATE` בניהול משתמשת בקטעים קבועים בלבד. |
| CSRF | בקשות שמשנות נתונים נבדקות מול Origin/Referer (ובלי אחד מהם: 403), בנוסף ל-`SameSite=Lax`. |
| עוגיות וסשנים | `HttpOnly`, `Secure` בפרודקשן, `SameSite=Lax`. בבסיס הנתונים נשמר רק hash של האסימון. מנהל 7 ימים, תלמיד 30. חסימה, איפוס סיסמה ופקיעת מנוי מנתקים מיד. נוקו אוטומטית כל 6 שעות. |
| הרשאות | כל נתיבי `/api/admin` מוגנים ב-`requireAdmin`. נתיבי תלמיד תמיד לפי המשתמש המחובר (`userId` לא נלקח מהבקשה). אין חשיפת נתוני תלמיד אחד לאחר. `password_hash` לא נשלח ללקוח. |
| XSS | React מקודד פלט, CSP קפדני (אומת בדפדפן ללא הפרות), `X-Frame-Options: DENY`. |
| כניסה | הודעה זהה למשתמש לא קיים ולסיסמה שגויה, זמן תגובה אחיד (hash דמה), נעילה זמנית אחרי כישלונות, `scrypt`. |
| סודות | אין קבצי `.env` או מפתחות במאגר, אין סיסמת בסיס נתונים בהיסטוריית Git. Secret Protection פעיל. |
| Offline | מצב API נדלק רק ב-`VITE_USE_API=true` ומנוטרל בדסקטופ. בדיקת האתר במצב דמו עברה. |
