# מסך עץ התוכן: מעבר מהמסך הישן

## מבנה הנתונים
- שאלה שמופיעה במקום אחד נשמרת בדיוק כמו קודם (`grade`, `subject`, `level`, `activityType`, `position`). אין המרה של נתונים קיימים ואין מיגרציה.
- שאלה שמופיעה בכמה מקומות מקבלת שדה `placements`: רשימת `{ grade, subject, level, activityType, position }`. המקום הראשון משוכפל לשדות הישנים.
- מקום מזוהה לפי קטגוריה, נושא ותת-נושא. שאלה מופיעה במקום פעם אחת, בתרגול או במבחן.
- צד התלמיד עובד על רשימה "פרוסה" (עותק תצוגה לכל מקום, עם אותו `id`). במבחן הכללי שאלה מופיעה פעם אחת.
- עותקים שנוצרו בעבר ("שכפול ושיוך") נשארים שאלות נפרדות.

## טבלת הפעולות (ישן → חדש)
| פעולה במסך הישן | איפה היא במסך החדש |
|---|---|
| חיפוש בנוסח או בתשובה | תיבת החיפוש מעל רשימת השאלות (בתוך המקום שנבחר בעץ) |
| סינון לפי קטגוריה, נושא, תת-נושא | בחירה בעץ. "כל השאלות" בראש העץ |
| סינון לפי פעילות | בורר "כל הפעילויות / תרגול / מבחן" |
| איפוס סינון | כפתור "ניקוי חיפוש" |
| דפדוף (25 בעמוד) | אותו דבר |
| בחירת שאלות / כל העמוד | תיבות סימון + "בחירת כל העמוד" |
| מחיקה קבוצתית | סרגל הבחירה: "מחיקה" |
| שינוי נושא או רמה מתוך הטבלה | "העברה" בשורה, או לכמה שאלות יחד מסרגל הבחירה |
| שינוי תרגול/מבחן מתוך הטבלה | לחיצה על תגית הפעילות בשורה |
| הזזה למעלה/למטה | חצים בתת-נושא (או בנושא בלי תתי-נושאים) |
| מיקום מספרי | שדה "מיקום" בעורך, לכל מקום בנפרד |
| עריכה מלאה (5 סוגי שאלות, הסבר, תשובות נוספות, רשימה) | כפתור "עריכה" |
| תצוגה מקדימה | בעורך, "תצוגה מקדימה" |
| שיוך לקטגוריה נוספת (עותק) | "שיוך" (אותה שאלה בכמה מקומות). עותק נפרד: "שכפול כעותק נפרד" בעורך |
| שאלה חדשה | "+ שאלה כאן" בעץ, או "שאלה חדשה" בראש המסך |
| הוספת נושא (שם, תיאור, תתי-נושאים, מצב מבחן) | "+ נושא" בעץ. מבחן נקבע לכל שאלה |
| שינוי שם נושא | בחירת הנושא בעץ, כפתור שינוי שם |
| מחיקת נושא | בחירת הנושא בעץ, כפתור מחיקה (עם הקלדת השם) |
| שיוך נושא לקטגוריה, עם או בלי שאלות | בחירת הנושא בעץ, "שיוך לקטגוריה". עם שאלות = אותן שאלות, מקושרות |
| מספר תתי-נושאים וסוג שאלות | בעץ ובכותרת המקום שנבחר |
| ייצוא כל השאלות לקובץ | בראש המסך |
| התראה על נושאים ששמורים רק בדפדפן | בראש לשונית התוכן |
| משתמשים, שחזור ויומן | ללא שינוי |

## חדש
- הוספה, שינוי שם, סידור ומחיקה של תתי-נושאים.
- תת-נושא ראשון בנושא: השאלות שהיו ישירות בנושא עוברות אליו.
- שאלות בלי תת-נושא בנושא שיש בו תתי-נושאים מופיעות תחת "ללא תת-נושא".

## מגבלות
- סדר הנושאים נשאר לפי א-ב (כמו אצל התלמידים). אפשר לסדר רק תתי-נושאים.
- שינוי שם נושא או תת-נושא: תלמיד שבאמצע תרגול שם יתחיל אותו מחדש. תוצאות קודמות נשארות תחת השם הישן.
