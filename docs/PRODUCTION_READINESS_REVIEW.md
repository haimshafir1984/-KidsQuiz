## מה נבדק ונמצא תקין
| תחום | ממצא |
|---|---|
| Turnstile בשרת | האימות נעשה בשרת מול Cloudflare, לפני כל בדיקה אחרת בהרשמה. בלי Token או עם Token לא תקין ההרשמה נדחית (400). כשל בשירות האימות חוסם (fail-closed). מדלגים עליו רק כש-`TURNSTILE_SECRET` ריק. |
| SQL Injection | כל השאילתות עם פרמטרים. הרכבת `UPDATE` בניהול משתמשת בקטעים קבועים בלבד. |
| CSRF | בקשות שמשנות נתונים נבדקות מול Origin/Referer (ובלי אחד מהם: 403), בנוסף ל-`SameSite=Lax`. |

| הרשאות | כל נתיבי `/api/admin` מוגנים ב-`requireAdmin`. נתיבי תלמיד תמיד לפי המשתמש המחובר (`userId` לא נלקח מהבקשה). אין חשיפת נתוני תלמיד אחד לאחר. `password_hash` לא נשלח ללקוח. |
| XSS | React מקודד פלט, CSP קפדני (אומת בדפדפן ללא הפרות), `X-Frame-Options: DENY`. |
| כניסה | הודעה זהה למשתמש לא קיים ולסיסמה שגויה, זמן תגובה אחיד (hash דמה), נעילה זמנית אחרי כישלונות, `scrypt`. |
| סודות | אין קבצי `.env` או מפתחות במאגר, אין סיסמת בסיס נתונים בהיסטוריית Git. Secret Protection פעיל. |
| Offline | מצב API נדלק רק ב-`VITE_USE_API=true` ומנוטרל בדסקטופ. בדיקת האתר במצב דמו עברה. |

### בדיקת Turnstile בצד השרת (אפשר להריץ בעצמך)
בקשה בלי Token. אמורה להיכשל בלי ליצור חשבון (אין להשתמש בנתונים אמיתיים):

```powershell
curl.exe -s -X POST https://kidsquiz.flowsbiz.com/api/auth/register -H "Content-Type: application/json" -H "Origin: https://kidsquiz.flowsbiz.com" -d "{\"acceptTerms\":true,\"firstName\":\"בדיקה\",\"lastName\":\"בדיקה\",\"city\":\"בדיקה\",\"email\":\"turnstile-test@example.invalid\",\"password\":\"Test1234\"}"
```
צפוי: `{"error":"אימות האבטחה נכשל, נסו שוב"}`. אם מתקבל `success`, `TURNSTILE_SECRET` לא נטען בשירות ה-API: למחוק את חשבון הבדיקה ולבדוק את המשתנה. (ייתכן שחסימת Cloudflare תחזיר 403 במקום זה, וגם זה תקין.)
