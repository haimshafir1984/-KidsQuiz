# הצעות עיצוב — KidsQuiz

מסמך מסכם המבוסס על המוקאפ ב‑`mockup.html`.
הכיוון הכללי: **מקצועי ונקי, נוח לילדים, אך לא ילדותי.**

---

## 1. רקע ושפת עיצוב כללית

### רקע
- **נשאר כמו היום** — גרדיאנט עדין `linear-gradient(135deg, #eef2ff 0%, #f8fafc 50%, #faf5ff 100%)` ב‑`index.css`.
- חשוב לוודא ש‑`background-attachment: fixed` קיים, כדי שהרקע יישאר במקום בזמן גלילה.
- לא להחליף ללבן ניטרלי — הגרדיאנט נותן חמימות בלי להיות צבעוני מדי.

### עקרונות עיצוב חדשים
- **פינות מעוגלות:** `12px` לכרטיסים (`rounded-xl`), `8px` לכפתורים (`rounded-lg`).
- **גבולות:** `1px` (`border`) במקום `2px` (`border-2`) — חוץ ממסך החידון שנשאר עם 2px.
- **טיפוגרפיה:** `font-bold` לכותרות (במקום `font-extrabold`); `font-extrabold` נשמר רק ל‑Hero של עמוד הנחיתה ולמסך החידון.
- **צללים:** עדינים מאוד (`shadow-sm`); ביטול `hover:-translate-y-0.5 hover:shadow-lg` בכרטיסי נחיתה וניהול.

### פלטת צבעים מצומצמת
| תפקיד          | צבע        | קוד       |
|----------------|------------|-----------|
| ראשי (מותג)    | brand‑600  | `#2563eb` |
| טקסט ראשי      | slate‑900  | `#0f172a` |
| טקסט משני      | slate‑600  | `#475569` |
| טקסט עזר       | slate‑500  | `#64748b` |
| הצלחה          | emerald‑600| `#059669` |
| אזהרה / מבחן   | amber‑500  | `#f59e0b` |
| שגיאה / מחיקה  | red‑600    | `#dc2626` |

## 2. עמוד נחיתה (`WelcomePage.jsx`)

> כיוון: ניקוי האימוג'י המיותרים, מעבר לאייקוני קו, היררכיה טיפוגרפית עדינה יותר.

### Header
- החלפת אימוג'י בכפתורי ניווט באייקוני קו מ‑`lucide-react`:
  - "בחירת כיתה 📚" → `<BookOpen />` + טקסט.
  - "ניהול 👤" → `<UserCircle />` + טקסט.
  - "התנתק 🚪" → `<LogOut />` + טקסט.
- הלוגו: ריבוע כחול עם אייקון `<BookOpen />` במקום `✨`.
- ה‑backdrop‑blur מוסר; רקע לבן אטום בלבד.

### Hero
- ה‑pill "פלטפורמת למידה צבעונית ומעודדת ✨" → "פלטפורמת למידה ותרגול" עם נקודה כחולה קטנה במקום אימוג'י.
- כותרת ראשית `text-4xl lg:text-5xl font-bold` (במקום `font-extrabold`).
- טקסט תיאור `text-lg text-slate-600` עם `leading-relaxed`.

### כרטיסי תכונות (FEATURE_CARDS)
- ריבוע צבעוני 14×14 → ריבוע אפור 9×9 (`bg-slate-100`) עם אייקון קו אפור.
- כותרת כרטיס `font-semibold text-base` (במקום `font-bold text-lg`).
- ביטול `hover:-translate-y-0.5 hover:shadow-lg`.

### כפתורי CTA
- "מתחילים עכשיו ✨" → "יצירת חשבון" + אייקון חץ.
- "כבר יש לי חשבון 🎯" → "כניסה לחשבון קיים" (ללא אייקון).
- `btn-primary` נשאר כחול; `btn-secondary` הופך ללבן עם גבול אפור (במקום כתום).

### כרטיס שאלת הדגמה
- pill "שאלת הדגמה 🎓" → "שאלת הדגמה" באפור עדין.
- אופציות התשובה ב‑grid 2×2 עם badge אפור על האות.
- הסבר תשובה נכונה — קופסה ירוקה עם אייקון `<CheckCircle />`.

## 3. מסך חידון (`QuizPage.jsx`)

> **לא משתנה. נשאר כמו היום.**

מה שנשמר:
- Header עם הלוגו `✨` ועם הכפתורים שמכילים אימוג'י (`חזרה ↩️`, `התנתק 🚪`).

- פס התקדמות עם גרדיאנט כחול‑סגול (`from-blue-600 to-violet-600`).

- LETTER_BADGES צבעוניים על אותיות התשובה (סקיי, אמרלד, אמבר, אינדיגו, רוז, ציאן).
- פינות `rounded-2xl` ו‑`border-2` בכרטיסי התשובות.

## 4. פאנל ניהול (`AdminPage.jsx`)

> כיוון: מעבר מתצוגת כרטיסים ענקיים לטבלה עם חיפוש, פעולות מרובות, וייבוא/ייצוא.

### 4.1 ארכיטקטורה — פיצול הקובץ
הקובץ הנוכחי `AdminPage.jsx` הוא **807 שורות** ומכיל 5 רכיבים פנימיים. הצעת פיצול:

```
src/pages/admin/
├── AdminPage.jsx              # router פנימי + טאבים
├── tabs/
│   ├── QuestionsTab.jsx
│   ├── TopicsTab.jsx
│   └── UsersTab.jsx
└── components/
    ├── QuestionForm.jsx
    ├── QuestionsTable.jsx
    ├── BulkActionsBar.jsx
    ├── ImportExportButtons.jsx
    ├── ConfirmDialog.jsx
    └── Toast.jsx
```

### 4.2 כותרת עליונה
- כותרת `text-2xl font-bold` (במקום `text-3xl font-extrabold`).
- שורת כפתורים בצד: `ייבוא` (אייקון Upload) | `ייצוא` (אייקון Download) | `שאלה חדשה` (כחול ראשי).

### 4.3 טאבים
מעבר משני טאבים (שאלות / משתמשים) לשלושה:
- **שאלות** + ספירה (לדוגמה `142`).
- **נושאים** + ספירה.
- **משתמשים** + ספירה.

עיצוב: גבול תחתון 2px בכחול לטאב הפעיל, ללא רקע מלא.

### 4.4 שורת סינון + חיפוש
החלפת ה‑`SectionToggle` הנפתח בשורה sticky קבועה עם:
- שדה **חיפוש טקסטואלי** (אייקון Search מימין) — מחפש בנוסח השאלה ובתשובה.
- 3 dropdowns: כיתה, נושא, פעילות.
- כפתור "איפוס" עדין.

זה הפיצ'ר החסר ביותר במצב הנוכחי.

### 4.5 פעולות מרובות (Bulk Actions)
פס שצף מעל הטבלה ברגע שנבחרת לפחות שאלה אחת:
- מציג "X שאלות נבחרו" + "בחר הכל בעמוד".
- כפתורים: **העברה לנושא**, **שכפול**, **מחיקה**.

### 4.6 טבלת שאלות
מחליפה את ה‑`QuestionRow` הנוכחי (כרטיס גדול לכל שאלה).

עמודות:
| ☐ | שאלה (+ תשובה בקטן) | נושא | רמה | סוג | פעולות |

- שורה: `py-3.5` עם hover אפור עדין.
- pill נושא: אפור.
- pill סוג פעילות: כחול לתרגול, ענברי למבחן.
- פעולות = 4 אייקונים בלבד (↑ ↓ עריכה 🗑) — ללא טקסט. כל אחד עם `title` ל‑tooltip.
- אייקון מחיקה — אדום עם hover אדום.

### 4.7 Pagination
- 25 שאלות לעמוד.
- מציג "1–25 מתוך 142".
- כפתורי `קודם` / מספרים / `הבא`.

### 4.8 ייבוא / ייצוא
- **ייצוא:** הורדת קובץ JSON של כל השאלות.
- **ייבוא:** העלאת קובץ JSON / Excel; תצוגה מקדימה לפני אישור.
- שילוב עם התיקייה הקיימת `_questions_import` (יש שם קובץ Word ששווה לפענח).

### 4.9 טופס שאלה — שיפורים
- במקום inline בתוך הדף, להעביר ל‑`Drawer` שנפתח מהצד (חוסך גלילה ארוכה).
- כפתור "תצוגה מקדימה" שמראה איך השאלה תיראה בפועל ב‑`QuizPage`.
- שדה תמונה: דרופזון להעלאת תמונה (במקום שדה URL בלבד, אם רלוונטי).
- חלוקה לסקציות: "תוכן השאלה" / "שיוך" / "שיוכים נוספים".

### 4.10 ניהול נושאים
- שדה inline editable במקום שני שדות נפרדים ("שם נוכחי" + "שם חדש").
- כפתור 💾 (אייקון Save) מופיע רק אחרי שינוי.
- כפתור 🗑 (אייקון Trash) באדום עדין בצד.

### 4.11 ניהול משתמשים (`AdminUsers.jsx`)
**זה האזור הכי דחוף לשדרוג** — כיום משתמש בשפת עיצוב ישנה.

שינויים נדרשים:
- החלפת `class="card"` ב‑`edu-card` (תאימות עם שאר הפרויקט).
- החלפת כל `text-purple-700/800` ו‑`bg-indigo-50/30` בפלטה האחידה (`text-slate-900`, `bg-blue-50`).
- הוספת **כרטיסי סיכום** למעלה: סה"כ תלמידים, ממוצע כללי, % מנויים פעילים.
- הוספת **מיון עמודות** בלחיצה על הכותרת.
- לחיצה על שורת תלמיד פותחת drawer עם פירוט מבחנים שלו.

## 5. החלפת `alert` ו‑`window.confirm`

| במצב הנוכחי                        | החלפה                              |
|-------------------------------------|--------------------------------------|
| `alert('יש להזין נוסח שאלה')`        | Toast מעוצב בפינה למשך 3 שניות      |
| `window.confirm('למחוק שאלה?')`     | מודאל פנימי `<ConfirmDialog />`     |
| `alert('נוסף שיוך חדש')`             | Toast ירוק עם אייקון ✓               |
| `alert('שאלה כבר קיימת')`            | Toast כתום עם אייקון אזהרה          |

יתרונות:
- תאימות RTL מלאה.
- עיצוב אחיד עם האפליקציה.
- אינו חוסם את המסך.

## 6. סדר עדיפויות מוצע ליישום

### שלב 1 — בסיס שפת העיצוב (משפיע על הכל)
1. הוספת `lucide-react` לפרויקט (`npm install lucide-react`).
2. עדכון `.edu-card` ב‑`index.css`: `border` במקום `border-2`, `rounded-xl` במקום `rounded-[20px]` (רק לכרטיסים שאינם מסך החידון).
3. הוספת מחלקה חדשה `.edu-card-quiz` שתשמר את הסגנון הקיים למסך החידון בלבד.

### שלב 2 — עמוד נחיתה
4. עדכון `WelcomePage.jsx` לפי סעיף 2.
5. עדכון `Header.jsx` עם אייקוני lucide.

### שלב 3 — פאנל ניהול
6. פיצול `AdminPage.jsx` למודולים (סעיף 4.1).
7. בניית `QuestionsTable.jsx` עם חיפוש + סינון.
8. הוספת `BulkActionsBar.jsx`.
9. בניית `ConfirmDialog.jsx` ו‑`Toast.jsx`; החלפת כל `alert/confirm`.
10. שדרוג `AdminUsers.jsx` לשפת העיצוב האחידה.

### שלב 4 — פיצ'רים מתקדמים
11. ייבוא/ייצוא JSON.
12. תצוגה מקדימה של שאלה.
13. Drawer לטופס שאלה.
14. כרטיסי סיכום ב‑AdminUsers.
